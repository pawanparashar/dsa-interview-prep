#3 — Two Sum

Arrays & Hashing LeetCode 1 NeetCode "Two Sum" Easy
Download one-pager (PDF) ↓

Problem

Given an array of integers nums and an integer target, return the indices i and j such that nums[i] + nums[j] == target and i != j. You may assume that every input has exactly one pair of indices that satisfies the condition. Return the answer with the smaller index first.

nums = [3,4,5,6], target = 7 → [0,1]
nums = [4,5,6], target = 10 → [0,2]
nums = [5,5], target = 10 → [0,1]

Watch the walkthrough

Core idea

Goal
Find two indices whose values add up to the target.

Key insight
Rearranging nums[i] + nums[j] == target gives nums[j] == target - nums[i]. A hash map lets you check in O(1) whether the complement you need has already been seen, so one pass is enough — no need to check every pair.

Trigger phrase: “Which other number do I need to hit the target?” → store what you've seen in a Hash Map and look up the complement.

Step through it

Walk the algorithm one step at a time — forward, back, or press play.

Walkthrough

Brute force checks every pair of indices for a match, which costs O(n²) time. Rearranging the target equation — nums[j] == target - nums[i] — turns the second number into something you can look up instead of search for, collapsing the pair-check into a single pass.

A Python dict gives O(1) average-case lookup and insertion, so for each number we can check ‘have I already seen the value that completes this pair?’ before moving on, rather than scanning the rest of the array.

Walk the array once. At each index i, compute diff = target - num. Check result first: if diff is already a key, you've found your pair — result[diff] is the earlier index and i is the current one, so the earlier index naturally comes first in the returned list. Only if diff isn't found do you store the current number's index for later lookups.

Because the problem guarantees exactly one valid pair, the first match found is the match — there's no need to keep scanning after the return.

Optimal solution

Data structure: Hash Map (Python dict) mapping value → index

  1. Initialize an empty dict result.
  2. Iterate through nums with index i.
  3. Compute diff = target - num — the value that would complete the pair.
  4. If diff is already a key in result, return [result[diff], i] immediately.
  5. Otherwise, store result[num] = i and continue.
O(n)Time
O(n)Space

Code

class Solution:
    def twoSum(self, nums: List[int], target: int) -> List[int]:
        result = {}
        for i, num in enumerate(nums):
            diff = target - num
            if diff in result:
                return [result[diff], i]
            result[num] = i

Other ways to solve it

Brute force — check every pair

Simplest to reason about and a safe fallback if you blank on the hash map trick: check every pair of indices directly. O(n²) time, but no extra space and nothing to get wrong.

class Solution:
    def twoSum(self, nums: List[int], target: int) -> List[int]:
        for i in range(len(nums)):
            for j in range(i + 1, len(nums)):
                if nums[i] + nums[j] == target:
                    return [i, j]
O(n²)Time
O(1)Space

Tips to remember this pattern

Mental shortcut — “What's missing? Look it up, don't loop for it.”

Edge cases to consider

  • Negative numbers and zero — diff = target - num works the same regardless of sign.
  • Duplicate values, e.g. nums = [5,5], target = 10 — the first 5 is stored before the second 5 looks up its complement, so i != j is naturally satisfied.
  • The same index can't be reused as both i and j, since the lookup happens before the current number is added to the map.
  • Problem guarantees exactly one solution exists, so there's no need to handle a ‘no pair found’ case.

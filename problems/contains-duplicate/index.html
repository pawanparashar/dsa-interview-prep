#1 — Contains Duplicate

Arrays & Hashing LeetCode 217 NeetCode "Duplicate Integer" Easy
Download one-pager (PDF) ↓

Problem

Given an integer array nums, return true if any value appears at least twice in the array, and return false if every element is distinct.

nums = [1,2,3,1] → true
nums = [1,2,3,4] → false
nums = [1,1,1,3,3,4,3,2,4,2] → true

Watch the walkthrough

Core idea

Goal
Determine whether any value repeats in the array.

Key insight
A hash set gives O(1) average-case lookup and insertion, so a single pass can catch a repeat the moment it's seen, with no nested loops.

Trigger phrase: “Have I seen this value before?” → reach for a Hash Set membership check.

Step through it

Walkthrough

Brute force compares every pair of elements, which costs O(n²) time. The moment we're willing to spend O(n) extra space, we can collapse that to a single O(n) pass.

A Python set is backed by a hash table, so num in h and h.add(num) are both O(1) on average. We only need to know “have I seen this number before” — we never need to know where or how many times, so a set is a better fit than a dict or list.

Walk the array once. For each number, check membership before inserting: if it's already there, you've found your duplicate and can short-circuit immediately rather than finishing the scan.

If the loop completes with no early return, every element was unique, so the answer is False.

Optimal solution

Data structure: Hash Set (Python set)

  1. Initialize an empty set h.
  2. Iterate through each num in nums.
  3. If num is already in h, return True immediately — duplicate found.
  4. Otherwise, add num to h and continue.
  5. If the loop finishes with no match, return False.
O(n)Time
O(n)Space

Code

class Solution:
    def hasDuplicate(self, nums: List[int]) -> bool:
        h = set()
        for num in nums:
            if num in h:
                return True
            else:
                h.add(num)

        return False

Tips to remember this pattern

Mental shortcut — “Seen it before? Set it and forget it.”

Edge cases to consider

  • Empty array → no duplicates possible, return False
  • Single-element array → return False
  • All elements identical → returns True as soon as the second element is checked
  • Negative numbers and zero → ints are hashable as-is, no special handling needed
